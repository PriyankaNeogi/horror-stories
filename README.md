# Horror Stories 💀 – The Era of Dark Animation

A production-grade, responsive website inspired by [ToonYug Animation](https://toonyuganimation.com), customized specifically for **Horror Stories** and 2D dark animation creators.

Live Demo & Free Deployment via GitHub Pages: [https://priyankaneogi.github.io/horror-stories/](https://priyankaneogi.github.io/horror-stories/)

---

## ✨ Features

- 💀 **Modern Dark Aesthetic:** ToonYug-inspired dark crimson and neon purple visuals, responsive navigation with dropdowns, search bar, and announcement ticker.
- 🎬 **Hero Banner Slider:** Dynamic multi-slide hero showcasing Horror Master Panel, Voice Actor Demos, and YouTube Creator Safety Guidelines.
- 👻 **2D Horror Marketplace:** Interactive asset catalog featuring 2D Ghost Rigs, Haunted Scenery, Monster Puppets, Cursed Props, and 100% Free Starter Packs with instant category filters.
- ⚡ **Horror Master Panel Feature Showcase:** Exact replica of ToonYug's Master Panel highlighting one-click character rigging, dynamic terror expressions, and auto camera parallax.
- 🎙️ **Interactive Voice Actor Audio Lab:** Audition dark whispers, banshee screams, demon growls, and ominous ambient drones powered in real-time by the Web Audio API.
- 🛒 **Slide-Out Shopping Cart & Quick Preview:** Full cart drawer, instant item preview modals, and seamless checkout workflow.
- 🚀 **Zero-Cost Automated GitHub Pages CI/CD:** Ready with GitHub Actions (`.github/workflows/deploy.yml`) for instant automated publishing on push.

## 🚀 One-Step Deployment to GitHub

1. Ensure the empty repository `horror-stories` exists under your GitHub account:
   [https://github.com/new](https://github.com/new) -> Name: `horror-stories`

2. Push from the desktop folder:
   ```bash
   cd ~/Desktop/horror-stories
   git push -u origin main
   ```

3. In your GitHub repository:
   - Go to **Settings** -> **Pages**
   - Under **Build and deployment**, select **GitHub Actions**
   - Your site will be live at `https://priyankaneogi.github.io/horror-stories/`
